# Jinju Bus web app implementation plan

> Execution: inline in this session; user explicitly requested continuation in this project. No deployment or ZERIONA edits.

**Goal:** Port the latest Android bus behavior into a responsive browser app and server API, with portable ZERIONA integration assets.

**Architecture:** Extend `mobile_app` using a standard-library Python HTTP server, isolated TAGO transport/service, and Leaflet browser UI. All app resources and API endpoints live beneath a configurable base path. Server environment variables hold the TAGO key; browser storage holds only this device's selections and successful public responses.

**Spec:** User's 2026-10-08 request and forwarded six-point ZERIONA integration brief in this task.

## Constraints and decisions
- Default mount `/apps/bus/`, default route `10`, refresh 15 seconds while visible.
- Query every exact route-number variant; use actual GPS only. No GPS means vehicle details without a map marker. Empty successful responses replace old vehicles; errors preserve clearly dated previous information.
- Hub return path is configurable, same-origin and relative. No second signup, trusted user header, or simulated login. Account storage is a future authenticated API integration, not device storage.
- Scope worker/cache to this app; never cache API or third-party tiles. Online map is distinct from Android's offline database.
- Assets: centered 1600×900 SVG banner, 512×512 SVG icon; metadata carries text separately. Manifest declares anonymous access and no demo data. Runtime health is a separate endpoint.
- Keep Android files and exports intact. Update existing web server; use no host-specific paths or external deployment.

## Review focus
- Nested/root base paths, traversal, encoded separators, and unrelated worker caches.
- Partial upstream failure, malformed/HTTP-200 error, missing GPS and stale marker direction.
- Removed routes and late responses, empty persisted selection, unavailable browser storage.
- Key leakage, false authentication and unbounded upstream requests.
- Narrow mobile viewport, keyboard access, map/CDN/network failure and honest status.
